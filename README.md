# Proyecto: Calculadora simple (Python)

Este repositorio contiene un conjunto de módulos Python para operaciones aritméticas básicas y un `main.py` de ejemplo que las utiliza.

Estructura de archivos
- `main.py` - Punto de entrada del programa.
- `sumar.py` - Función para sumar.
- `restar.py` - Función para restar.
- `multiplicar.py` - Función para multiplicar.
- `dividir.py` - Función para dividir.
- `pedir.py` - Utilidades para pedir entrada al usuario.
- `par.py` - Funciones auxiliares (por ejemplo, comprobaciones de paridad).

Requisitos
- Python 3.7+ (no hay dependencias externas).

Uso
1. Ejecuta el programa principal:

```bash
python main.py
```

2. Sigue las instrucciones en pantalla para realizar operaciones.

Notas
- Proyecto educativo y sencillo; puedes importar los módulos desde otros scripts.
- Si quieres, puedo añadir ejemplos concretos de uso o añadir pruebas unitarias.
